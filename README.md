## Experiencia 💼

Desarrollador de software enfocado en backend con Java y Spring Boot: microservicios, mensajería con Kafka, implementacion del api de factus con la normativa fiscal de la DIAN. Complemento mi trabajo con interfaces en Angular y React. Me enfoco en código limpio, eficiente y listo para producción.

<br>

## Proyectos

🚀 **FinNode**: Core bancario y motor de pagos distribuido, basado en microservicios con Java, Spring Boot y Kafka. Procesa transferencias de alta concurrencia con el patrón Saga y contabilidad de partida doble, notifica el resultado en tiempo real por WebSocket e incluye un microservicio independiente de detección de fraude (Python + FastAPI) que evalúa cada transacción antes de reservar fondos.

📑 **Sistema de Facturación Electrónica**: Plataforma web full-Stack que automatiza la emisión de comprobantes fiscales, integrando la API de Factus, que gestiona la firma digital y el cumplimiento normativo ante la DIAN.

🌱 **Ecoafa**: Sitio web desarrollado a la medida para el sector ambiental, desplegado en producción y optimizado para SEO y diseño responsive.

🦷 **Dental Appointment Manager**: Aplicación web de gestión clínica que optimiza el agendamiento de citas médicas mediante un módulo centralizado de mensajería interactiva entre pacientes y personal.
